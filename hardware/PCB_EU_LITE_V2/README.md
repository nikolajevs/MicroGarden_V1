# MicroGarden_V1 — плата EU-LITE V2

**Состояние на 28.10.2026: начата V2; есть схема, `design.json` и BOM. Платы
(расстановки и разводки) ещё нет.** KiCad-проверки ERC/DRC для V2 не выполнялись,
стендовые испытания — тоже. V1 ([PCB_EU_LITE](../PCB_EU_LITE/README.md), выпуск r3)
остаётся без изменений.

V2 — это EU-LITE V1 с другим светом. Вместо LM3429 и повышающего DC-DC на 48 В
плата питает **шесть ламп 24 В / 25 Вт с постоянным напряжением** (KQO QL63,
Samsung LM281B+) и только регулирует мощность: один ключ по минусу на все лампы,
ШИМ 1 кГц с GPIO25. На каждом выходе свой предохранитель 2 А. Из-за 150 Вт света
вход рассчитан на БП **24 В / 15 А** (предел платы 13 А). Остальное — как в V1:
ESP32-WROOM-32E, 12 В и 3,3 В, PTC 100 Вт, помпа, два вентилятора, INA238, RTC,
microSD, SHT4x, поплавок и RGB-индикатор.

Решения, расчёты и открытые вопросы — в [DESIGN.md](DESIGN.md).

## Подключение ламп

| Клеммник | Вывод 1 | Вывод 2 |
|---|---|---|
| J501…J506 (KF301-5.0-2P) | +24 В лампы, через свой F501…F506 2 А | **LED_NEG** — общий коммутируемый минус ламп |

LED_NEG — **не земля**. Минус и алюминиевый корпус лампы нельзя соединять с GND
платы или с заземлённым корпусом: такая лампа обойдёт ключ и не выключится.
Яркость — скважность ШИМ; ток лампы плата не регулирует. До подключения всех
шести ламп измерить ток одной при 24,0 и 25,0 В (расчёт допускает до 1,25 А).

## Проверки

Выполнено 28.10.2026 на Python 3.13 без KiCad:

| Проверка | Результат |
|---|---|
| `tools/verify.py` | 56 проверок пройдены: цепи, номиналы, ключ и драйвер ламп, предохранители, бюджет 13 А, склад и цены |
| `tools/test_verify.py` | 35 преднамеренных дефектов отклонены, исходный проект проходит |
| `tools/check_schematics.py` | 166 символов (с флагами питания и площадками), 424 вывода прослежены по записанным листам, 1442 UUID, 0 проблем |
| Регенерация в отдельной копии | Генератор воспроизводит все файлы V2 байт в байт |
| `tools/check_standalone.py` (корень) | Пройден для V1 и V2: локальные библиотеки, посадки, модели, ссылки документации |

**Не выполнено:** ERC/netlist/DRC в KiCad 10.0.7 (в среде нет KiCad), расстановка и
разводка, Gerber, нагрев и любые стендовые испытания. Программные проверки не
подтверждают работу платы.

Команды из корня репозитория; результаты — в `work/`:

```sh
python -c "from pathlib import Path; Path('work').mkdir(exist_ok=True)"
python tools/check_standalone.py
python hardware/PCB_EU_LITE_V2/tools/verify.py --output work/v2_connectivity.txt
python hardware/PCB_EU_LITE_V2/tools/test_verify.py
python hardware/PCB_EU_LITE_V2/tools/check_schematics.py
```

Генератор перезаписывает схемы, `design.json` и BOM. После ручной правки в KiCad
сначала перенести её в `tools/generate.py`; регенерацию проверять в отдельной копии.
